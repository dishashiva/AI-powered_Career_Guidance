# Project Prompt: AI-Powered Career Intelligence Platform

## Project Overview

Build a scalable, user-friendly, **AI-Powered Career Intelligence Platform** designed to solve the complexities of modern career planning. Unlike traditional job portals that only host listings, this platform acts as an intelligent career coach. It analyzes user resumes, identifies skill gaps, recommends optimal career paths, suggests tailored learning resources, predicts salary ranges, and provides personalized career insights.

---

## Tech Stack

* **Frontend:** React.js (Single Page Application, responsive dashboard UI)
* **Backend:** FastAPI (Python-based, asynchronous, high-performance REST API)
* **Database:** MySQL (Relational database for structured user profiles, skills, jobs, and courses)
* **AI/ML Layer:** OpenRouter API (Accessing LLMs for NLP resume parsing, skill analysis, and chatbot interactions)

---

## Core System Architecture & Features

### 1. Frontend (React.js)

* **Landing & Auth:** Clean landing page with User Registration and Login.
* **User Dashboard:** Central hub featuring a **Resume Upload** widget (supporting PDF/Docx).
* **Career Dashboard:** A comprehensive, data-driven panel that visualizes career insights, ATS scores, and recommended paths using interactive charts.
* **Job & Course Recommendations:** Dedicated feeds displaying personalized job matches and structured learning resources.
* **AI Career Assistant:** An integrated chat interface for real-time user interaction with the AI coach.

### 2. Backend (FastAPI)

* **Authentication Service:** JWT-based user signup, login, and secure session handling.
* **User Profile Service:** Manages CRUD operations for user profiles, histories, and preferences stored in MySQL.
* **Resume Management Service:** Handles secure file uploads and structures parsed metadata.
* **Recommendation & Admin Services:** Coordinates business logic for fetching job/course matches and system metrics.
* **AI Processing Controller:** Bridges the backend and the OpenRouter API to execute prompt pipelines asynchronously.

### 3. Database Layer (MySQL)

Design a relational schema containing the following key entities:

* `Users` & `Profiles` (Auth details, contact info, experience levels)
* `Resumes` (Stored metadata, text extracts, and parsing timestamps)
* `Skills` & `Skill_Gaps` (Master skill inventory and per-user missing skills)
* `Jobs` & `Courses` (Scraped/indexed career opportunities and learning resource links)
* `Recommendations` (Logs of historical matches generated by the AI)

### 4. AI / ML Engine (OpenRouter API Integration)

Leverage OpenRouter to power the following core logical functions via structured prompt engineering:

* **Resume Parser (NLP) & Skill Extraction:** Parse text from uploaded resumes to extract structured data (skills, roles, experience).
* **ATS Score & Skill Gap Analysis:** Compare the user's current profile against standard industry benchmarks to output a percentage score and list missing requirements.
* **Career & Job Matching:** Predict logical next-step career paths and filter relevant job titles.
* **Salary Prediction:** Estimate potential salary bands based on skill sets and target roles.
* **AI Career Chatbot:** A conversational LLM interface that references the user's parsed profile data to answer career questions contextually.

---

## Technical & Non-Functional Requirements

* **Performance:** The FastAPI backend must handle asynchronous OpenRouter API requests smoothly without blocking core database operations.
* **Data Structure:** All LLM outputs via OpenRouter should leverage `JSON mode` or strict schema prompts where applicable (e.g., for parsing resumes and skill lists) to ensure clean ingestion into the MySQL database.
* **Scalability:** The architecture must decouple heavy text processing/AI calls from standard user CRUD workflows.
